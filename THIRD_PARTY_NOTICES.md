# Third-party notices

RetroZ S1 depends on external Python projects. They are installed from the
normal package index and are not copied into this repository.

Runtime dependencies:

- NumPy — numerical array processing
- Pillow — image input/output and synthetic figures

Development and documentation dependencies:

- pytest and pytest-cov — tests and coverage
- PyYAML — structured-document validation
- Matplotlib — report PDF generation
- MkDocs — documentation site generation
- Ruff — static checks
- build — wheel and source-distribution builds

Each dependency remains governed by its own license and distribution terms.
No model weights, protected media or bundled third-party source package is
included.
