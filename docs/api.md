# API and CLI Reference

`python -m retroz_s1 list-candidates` lists frozen statuses. `inspect` prints structured metadata. `render --candidate B` runs monotone shoulder remapping; `render --candidate D3` runs source-fixed geometry and contour coverage. `reproduce-failure` supports A and C. `oracle-render` requires user-supplied labels.

Every rejected or historical execution requires `--allow-rejected-research-candidate`. This is an acknowledgement, not a recommendation.
