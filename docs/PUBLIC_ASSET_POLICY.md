# Public asset policy

The repository may contain:

- original source code and documentation;
- procedural fixtures and renders derived from those fixtures;
- diagrams, plots and amplified deltas generated from public-safe data;
- structured summaries and hashes that do not reveal private source material.

The repository must not contain:

- protected animation frames, crops, contact sheets or videos;
- frame-derived candidate outputs from protected media;
- private contour coordinates or exact private masks;
- private-session exports or workstation paths;
- credentials, tokens or personally identifying local metadata.

Every committed image must be either under `examples/synthetic/`, under
`docs/assets/generated/`, or the generated social preview in `docs/figures/`.
The repository verifier enforces this boundary.
