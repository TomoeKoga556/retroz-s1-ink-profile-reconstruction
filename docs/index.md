# RetroZ S1

RetroZ S1 investigates whether a small, deterministic image operator can change
selected ink-edge profiles while keeping the perceived contour, color plateaus
and protected regions stable.

The evaluated answer is **no under the tested constraints**. None of the five
lineages produced a clearly useful visible improvement, so the production
behavior remains identity/bypass.

![Synthetic candidate comparison](assets/generated/candidate-comparison.png)

This site documents the question, the evaluation design, the candidate results
and the boundary between publicly reproducible material and private historical
evidence.
