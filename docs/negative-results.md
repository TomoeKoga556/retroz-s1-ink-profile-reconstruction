# Negative result

The final claim is intentionally narrow:

> No tested S1 candidate demonstrated a clearly useful, production-worthy
> visible effect under the evaluated data, metrics, safety gates and review
> protocol.

That statement does not say that retro line reconstruction is impossible. It
does say that the evaluated local deterministic families no longer justify
production activation or more strength sweeps without new evidence.

## Why keep the repository

The negative result records several reusable lessons:

- a reference edge-width gap does not guarantee a safe local inverse operator;
- synthetic correctness does not guarantee real-distribution activation;
- candidate-owned diagnostics are not a substitute for independent measurement;
- perfect localization can still feed a renderer whose effect is perceptually irrelevant;
- stopping a closed family is a valid engineering outcome.

The public package makes these lessons inspectable while keeping protected media
and private labels out of the repository.
