# One Minute Project Pitch

I investigated whether deterministic local image operators could shift modern digital ink profiles toward selected cel-animation references without damaging geometry or color. I built preregistered candidates, a fail-closed evaluator, sandbox and provenance checks, and a final human-labeled Oracle test. The filters did not earn production activation, but the project produced a rigorous, reusable visual-computing evaluation framework and a reproducible account of why plausible methods failed.
