# Public Release Checklist

- [x] Public and private packages are physically separate.
- [x] Public visuals are synthetic-only.
- [x] Candidate statuses are fail-closed.
- [x] Public provenance uses sanitized source identifiers.
- [ ] Maintainer selects a final repository license.
- [ ] Maintainer manually reviews the final PDF and social preview.
- [ ] Maintainer creates the remote and performs the first commit, if desired.

No remote, commit, tag, release, or push is performed by the packaging workflow.
