# Source and asset boundaries

This repository contains code, documentation and generated assets prepared for
the RetroZ S1 project. The Apache-2.0 license applies to project material for
which the repository owner holds the relevant rights. A file with its own notice
keeps that notice.

Third-party Python packages are installed as dependencies and are not vendored.
Their respective licenses continue to apply; see `THIRD_PARTY_NOTICES.md`.

The public tree does not include protected animation frames, frame crops,
contact sheets, videos, private contour labels, exact workstation paths or raw
private-session logs. Public visual examples are produced from synthetic
fixtures. Historical real-data findings are reported as bounded summaries, not
as publicly replayable datasets.

Contributions must follow the same boundary: use original, licensed or synthetic
material and document the source of any non-trivial asset.
